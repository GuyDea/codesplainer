Understand any codebase, one diagram at a time.

Ask a question about your code and get a small diagram back, not a wall of text. Expand any box into a deeper diagram, step through flows, and jump to the lines behind every box and arrow.

Download Try the demo

Codesplainer runs on your machine with the AI coding agent you already have: Kiro CLI, Claude Code, Codex or any ACP agent. Agents read your code locally, read-only. No account, no telemetry.

Try it with sample diagrams

These diagrams explain Codesplainer itself. Switch between them with the tabs; on the Flow and Sequence samples, press P to step through the numbered arrows. In the app, every box and arrow links to your code.

Download

Free and open source (MIT). All releases

macOS

Apple Silicon (.dmg) Intel (.dmg)

Not signed by Apple yet: open the app once, then go to System Settings → Privacy & Security and click Open Anyway.

Windows

Installer (.exe, x64)

Not signed yet, so SmartScreen may warn about it: click More info, then Run anyway.

Linux

Debian / Ubuntu (.deb) AppImage (x86_64)

Install the .deb with sudo apt install ./Codesplainer-linux-amd64.deb. The AppImage needs libfuse2 (libfuse2t64 on Ubuntu 24.04) and chmod +x.

You also need at least one agent CLI installed and logged in: Kiro CLI, Claude Code, Codex or any ACP agent. Without one, the offline demo provider still lets you try the app.

Or run it from source

With Node.js 22.12 or newer, the command line version opens Codesplainer in your browser. It shares settings and conversations with the desktop app (~/.codesplainer). 

git clone https://github.com/GuyDea/codesplainer.git
cd codesplainer
npm install
npm run build
npm start
